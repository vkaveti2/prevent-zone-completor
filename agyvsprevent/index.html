How the Automation Works

1. 16x Speed Injection

Dynamically creates a <div class="cs-listitem menu-choice" data-speed="16"> element inside Articulate Storyline's playback speed dropdown. Sets media playbackRate = 16 and triggers internal DS.appState.setPlaybackSpeed(16) loop.

2. Smart Quiz Selector

Solves quiz questions in both Moodle quizes (.que) and Storyline embedded slides. Filters out hidden dummy inputs (value="-1"), checks valid options, and dispatches change, input, and click DOM events.

3. Auto-Next Observer

Monitors disabled or hidden #next and #submit buttons across frames. Automatically unlocks disabled attributes when media completes and triggers clicks to advance to the next slide or section.

Installation & Setup Instructions

Method 1: Tampermonkey Userscript (Recommended)

  1. Install the Tampermonkey extension in Chrome, Edge, or Firefox.
  2. Click the Tampermonkey icon in your browser extension bar and select "Create a new script...".
  3. Delete the default template, click the Copy Userscript Code button above, and paste it.
  4. Press Ctrl + S to save.
  5. Open your Prevent Zone training page. The ⚡ floating control widget will appear in the bottom-right corner!

Method 2: Chrome / Edge Developer Extension

  1. Open Chrome or Edge and go to chrome://extensions/ or edge://extensions/.
  2. Enable "Developer mode" in the top right corner.
  3. Click "Load unpacked".
  4. Select the chrome-extension folder inside this workspace (C:\Users\kavet\Downloads\preventzone\chrome-extension).
  5. The extension icon will now appear in your browser toolbar!

Method 3: DevTools Console (Instant / No Install)

  1. Open any Prevent Zone training page or player.
  2. Press F12 (or Right Click -> Inspect) and switch to the Console tab.
  3. Click Copy DevTools Script above, paste it into the console, and hit Enter.
